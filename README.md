# Slime Escape

Unity 감각을 다시 익히기 위해 제작한 2D 퍼즐 탈출 연습 프로젝트입니다.

## 프로젝트 개요
- 장르: 퍼즐 탈출맵
- 개발 엔진: Unity 2022.3.4f1
- 개발 기간: 약 2달
- 목적: Unity 기본 조작, 충돌 처리, 상호작용, 상태 분기 구조를 다시 익히기 위한 개인 연습 프로젝트

## 주요 구현
- 색깔별 슬라임 타입 기능 구현
- 바닥 타입과 플레이어 타입 체크
- 열쇠 아이템 획득 및 문 상호작용
- 레버 작동에 따른 물 상승 기믹
- 적 슬라임의 플레이어 타입 인식
- 타입 불일치 시 데미지 처리

## 기술 포인트
- 플레이어 하단 콜라이더를 통해 현재 닿아 있는 바닥 타입 체크
- 바닥 타입과 슬라임 타입을 Enum으로 관리
- 초록 / 파랑 / 빨강 슬라임에 따라 땅, 물, 용암 대응 방식 분리
- 잘못된 타입으로 일정 시간 이상 머무르면 데미지 처리
- 열쇠 획득 시 플레이어 뒤를 따라오도록 처리하고, 문과 상호작용 시 소모
- 레버 작동 시 물 오브젝트가 지정된 높이와 시간에 따라 움직이도록 구현
- 적 슬라임은 플레이어 타입을 확인한 뒤 반응하도록 구성

## Note
공익 복무 이후 Unity 개발 감각을 다시 익히기 위해 제작한 연습 프로젝트입니다.  
상업적 목적보다는 Unity의 기본 충돌, 상호작용, 상태 분기, 오브젝트 이동 흐름을 복습하는 데 중점을 두었습니다.
